See what a program really does.

Four things it tells you that nothing else does.

The sandbox has 38 fake secrets where real info-stealers look: SSH keys, browser passwords and cookies, crypto wallets, Telegram and Discord sessions, cloud and developer tokens. None of them are real, and each carries its own mark.

Which secret, and which program

An eBPF tracer in the kernel names the process behind every file it opened. npm reading its own .npmrc is normal; its install script reading it is not, and chouf tells them apart.

PROOF · AWS keys → evil.example

Proof of what left the machine

Each bait's mark is looked for in what the program sends, as is, base64-encoded or hidden in a DNS name. Over HTTPS, it says what was sent, and where, right after the secrets were read.

cron · .bashrc · service

What it planted for later

A scheduled task, a line in .bashrc, a service: chouf sets each one off once, still watching. A thief that waits for your next login gets caught now.

192.168.1.1:80 refused

Your home network stays out of reach

The program reaches the internet, never your router or your other machines, IPv6 included. Every attempt is refused and reported: probing your network is a red flag.

How it works

The program runs as root, but only a copy of the system is touched, and the copy is thrown away.

01

A throwaway machine

A rootless podman container that looks like a desktop: pid 1 is systemd, GNOME and Firefox are running.

02

A home full of bait

38 realistic fake secrets, each with a unique mark that traces any leak back to this run.

03

Eyes in the kernel

chouf-trace (eBPF) sees every program started, file opened, connection made and DNS answer.

04

A report for anyone

In short, then the detail, and what to do if you already ran it. In English or French, and as a page to share.

Some programs only misbehave when you use them.

chouf explore lets an AI drive the program like a careful tester, then compares what it says with what it did. The verdict is an opinion; the findings next to it are measured.

  1. Runs themectl: it prints its help.
  2. Tries list, then install nordic: a question.
  3. Runs it again and types y.
  4. Tries sync, “to keep themes up to date”.
  5. Sees a process sleeping in the background, and waits 20 s.
  6. The theft happens. chouf sees tar read the keys and bash send them out.
